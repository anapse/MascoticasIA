### 📐 Formato de Sprite Sheet (Cuadrícula 3 × 3):

Cada imagen PNG debe contener una cuadrícula uniforme de 3 columnas × 3 filas con las 9 emociones en el siguiente orden obligatorio:

```
┌─────────────────┬─────────────────┬─────────────────┐
│  1. FELIZ       │  2. MOLESTO     │  3. RISA        │
│  (Fila 0, Col 0)│  (Fila 0, Col 1)│  (Fila 0, Col 2)│
├─────────────────┼─────────────────┼─────────────────┤
│  4. CURIOSO     │  5. SORPRESA    │  6. DURMIENDO   │
│  (Fila 1, Col 0)│  (Fila 1, Col 1)│  (Fila 1, Col 2)│
├─────────────────┼─────────────────┼─────────────────┤
│  7. COMIENDO    │  8. SALUDA      │  9. PENSANDO    │
│  (Fila 2, Col 0)│  (Fila 2, Col 1)│  (Fila 2, Col 2)│
└─────────────────┴─────────────────┴─────────────────┘
```
