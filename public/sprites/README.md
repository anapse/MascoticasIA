## Formato

Cada mascota usa una hoja 3 × 3 con este orden fijo:

1. FELIZ
2. MOLESTO
3. RISA
4. CURIOSO
5. SORPRESA
6. DURMIENDO
7. COMIENDO
8. SALUDA
9. PENSANDO

La aplicación recorta las celdas matemáticamente. Las imágenes originales no se modifican.
